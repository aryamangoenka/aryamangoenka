## Things I've built

**Extractify @ ASAPP** — agentic NLP system (LangGraph) for structured extraction from customer conversations. Hybrid regex + LLM pipeline on Gemini 2.5 Flash that processed 10K+ multi-turn dialogues at 95–100% accuracy on key fields; benchmarked with PCA/KMeans and KNN (F1 > 0.85). Presented to ASAPP's ML leadership.

**NeuroBlock** — drag-and-drop neural network builder for ML education. Students build, train, and export models (classification, regression, CNNs) with real-time feedback. Used by 500+ high schoolers.

**ML for Education Lab @ UMass** — evaluated frontier LLMs (GPT-4.5, Gemini 2.5, Claude 3.7, DeepSeek-R1) against WCRF/AICR clinical guidelines for accuracy, consistency, and bias. Built a multi-agent pipeline for parallelized evaluation; this work became the NUTRITION 2026 paper.

**Industry work** — full-stack user management system at Paktolus (Django REST, FastAPI, Next.js 15, TypeScript, JWT auth + RBAC, 80%+ test coverage); React dashboards at telSpiel supporting 150M+ daily interactions.
